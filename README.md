## 3. Модульні перевірки

Чисті функції в `script.js` (не читають DOM):

- `validateInput(value)`: перевірка тексту;
- `filterItems(list, query)`: фільтрація меню за назвою;
- `isValidRoute(name, list)`: перевірка назви маршруту.

Файл `tests.js` підключено після `script.js` з атрибутом `defer`. Функція `runUnitTests()` викликається при завантаженні. У вкладці Console немає повідомлень `Assertion failed`.

## Обмеження

Без сторонніх залежностей: лише Chrome DevTools Lighthouse та `console.assert()`. Дані користувача виводяться тільки через `textContent`. Тести не змінюють інтерфейс і не пишуть у `localStorage`.
